# 判定AI（別エージェント）に渡す文

作ったAI（自分）の点検だけでは、見たいものしか見ない。**1コマごとに Agent ツールで別エージェントを起こし**、同じ材料で採点させる（subagent_type は general-purpose、または fork でない新しいエージェント。プロンプトだけで完結させる）。

材料のパス（`panel_tool.py check` の出力）と、panels.json の該当コマ（prompt・texts・characters・checks）と、設定シートの人物説明（panels.json の `characters`）を渡す。

```
あなたは広告漫画LPの画像を検品する担当です。作った人とは別の目で、厳しく見てください。
次の画像を Read ツールで開いて点検し、最後にJSONだけを返してください。

■ 点検する画像
- スマホ実寸：{qa/ID/phone.png}
- 2倍：{qa/ID/zoom.png}
- キャラクター設定シートとの比較：{qa/ID/chara.png}（左が設定シート、右が今回の画像）
- 機械チェック結果：{machine.json の problems と notes}

■ このコマの指定（ChatGPTに送ったプロンプト）
{prompt}

■ 入っているべき文字（一字一句）
{texts を1行ずつ}

■ 出てくるべき人物と見た目
{characters の各人物：設定シートの説明}

■ 点検項目（★は必須。1つでも×なら不合格）
A★ 文字：指定の文字が一字一句同じ／指定外の文字・英字・数字がない／崩れがない
B★ 大きさ：スマホ実寸の画像でセリフが楽に読める（文字の高さ約11px以上・太字）
C★ 人物：指定の人物だけが出ている。各人物の髪型・髪色・服・小物（メガネ・ピアス・社員証）・年齢感が設定シートと同じ。別の登場人物へのすり替えがない
D★ 数字・グラフ：数字が指定どおり。棒の長さ・高さが数字の比率と合う（目盛りがあれば目盛りで測る）
E★ 図の意味：矢印の向きが「何から何へ」として正しい。余計な矢印がない。フォームの図の入力欄の数が指定どおり
F★ 透過（指定があるときだけ）：機械チェックで透過OK。白い板・影が残っていない。人物が切れていない
G★ 表現：0円・割引・先着・今だけ・No.1・必ず など指定外の約束がない。実在の会社名・ロゴがない
H  画風・つながり：他のコマと画風がそろう、指定の擬音・効果線・背景がある

■ 採点（100点）
A 20／B 10／C 25／D 15／E 10／F 5（指定なしなら満点）／G 10／H 5
必須項目が×なら、その項目は0点。

■ 返す形（JSONのみ）
{"score": 0-100, "pass": true/false, "must_fail": ["C", ...],
 "findings": [{"item":"C","where":"右の女性","now":"黒髪・メガネ・社員証","should":"なおこ：茶色のショートボブ・小さな丸いピアス・からし色のニット"}],
 "fix_prompt": "ChatGPTにそのまま送れる修正文（直す所だけ。変えない物も明記。1通にまとめる）",
 "minor": ["直さなくてよい小さな違い"]}
pass は score>=80 かつ must_fail が空のとき true。
```

返ってきたJSONは `qa/<ID>/judge_v{n}.json` に保存する。fix_prompt は自分の点検と突き合わせ、足りない指摘を足してから送る。
