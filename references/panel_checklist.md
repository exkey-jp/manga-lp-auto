# 1コマの点検チェックリスト（工程④）

ChatGPTの画像は「だいたい合っている」ことが多く、**見落としやすいのは人物のすり替えと図の意味の誤り**。太陽光＋蓄電池の漫画LP（2026-10、30枚）では、30枚中9枚で直しが要った。次の項目は全部そこで実際に起きたもの。

点検の材料は `panel_tool.py check` が作る：
- `qa/<ID>/phone.png` … スマホでの実寸（幅390px）。**文字の大きさはこれで判断**
- `qa/<ID>/zoom.png` … 2倍。セリフを一字一句読むとき
- `qa/<ID>/chara.png` … キャラクター設定シートと並べたもの。**人物の確認はこれで**
- `qa/<ID>/machine.json` … サイズ・比率・背景透過・前の版と同じでないか（機械チェック）

## 判定の流れ

1. `machine.json` の problems が1つでもあれば NG（目で見る前に直す）
2. 下の A〜H を上から順に見る。**必須（★）が1つでも×なら NG**
3. 別AI（`judge_prompt.md`）にも同じ材料で採点させる。**80点未満か、必須×なら NG**。自分と判定AIの低い方を採る
4. NG → 「修正プロンプトの型」で直しを1通にまとめて送る。**最大3回**。3回で通らなければ止めて人に聞く（`panel_tool.py mark … stop`）
5. OK → `panel_tool.py mark <案件> <ID> ok --score N` → 次のコマ

「直さなくてよい小さな違い」（背景のぼやけた英字、遠景の小物）は OK にして、メモだけ残す。LPの表示サイズで読めない・気づかないものは直さない（直すたびに他が崩れるリスクがあるため）。

## A. 文字（★）

| 見ること | 合格 | 例 |
|---|---|---|
| A1 セリフ・見出しが指定と**一字一句**同じ | panels.json の `texts` を全部、zoom.png で1文字ずつ照合。句読点・「…」「!?」・全角半角まで | — |
| A2 指定していない文字がない | 看板・書類・スマホ画面・モニターの中に文字や数字がない（線と四角でぼかしてある）。英字のロゴ風の文字もNG | M05：遠景の黒板にぼやけた英字 → 読めないのでOK |
| A3 文字が崩れていない | 存在しない漢字・つぶれた字・左右反転がない | — |
| A4 縦書き・横書きが指定どおり | 吹き出しは縦書き指定。見出しは横書き | — |

## B. 文字の大きさ（★）

| 見ること | 合格 |
|---|---|
| B1 スマホで読めるか | phone.png で、**セリフの文字の高さが約11px以上**（漢字1文字が390px幅の約1/35以上）。細い明朝・細ゴシックは不可 |
| B2 他のコマとそろっているか | 同じLPの他のコマと比べて、文字だけ極端に小さい・細いコマがない |

例 **M23**：セリフが細く小さく、スマホで約9px → 「今の約2倍の太いゴシック体、吹き出しも大きく」で直した。

## C. 人物（★） — いちばん多いNG

`chara.png` で、**登場するはずの人物ごとに**髪型・髪色・顔立ち・服・小物（メガネ・ピアス・社員証）を1つずつ照合する。

| 見ること | 合格 |
|---|---|
| C1 人数と役が合っている | 指定した人物だけが出ている。別の登場人物や知らない人に**すり替わっていない** |
| C2 髪型・髪色 | 設定シートどおり（結んでいる/いない、長さ、黒/茶） |
| C3 服・色 | 設定シートどおり。**服の色で見分けている人物は特に**（子どもの黄色T、友人のからし色ニット等） |
| C4 小物 | メガネ・ピアス・社員証の有無が設定どおり。**社員証やメガネが友人役に付くと「会社の人」に見える** |
| C5 年齢感 | 若返り・子どもの幼児化がない |

実例：
- **S02**：「みか＋けんじ」のはずが、なおこ（茶髪ボブ・からし色）と別人の男性。→ 作り直し
- **M14**：けんじがくせ毛で若い別人。→ 「短く整った黒髪・45歳」に
- **M16**：友人なおこが、黒髪・メガネ・社員証の別人（相談スタッフ風）に。みかも茶髪。→ 場面の意味が「会社の人が止める」に変わるので必須で直す
- **M20**：相談スタッフが茶髪・ジャケット → なおこと見間違える。→ シートどおり（黒髪ボブ・紺ベスト・社員証）に
- **M24**：そうたが白地に青袖Tシャツ・茶髪 → 黄色T・黒髪に
- **M26**：スタッフにメガネ → 外す
- **P0（設定シート）**：スタッフと主人公がどちらも黒髪の1つ結びで見分けにくい → スタッフをショートボブに。**設定シートの段階で「並んだときに髪型と服で見分けられるか」を確認する**

## D. 数字とグラフ（★）

| 見ること | 合格 |
|---|---|
| D1 数字が指定どおり | 桁・カンマ・単位・「約」「最大」まで |
| D2 足し算・比率が合う | 合計・倍率を計算して確かめる（M13：74＋255＋60＝389、M17：1,314÷325＝約4倍） |
| D3 **棒の長さ・高さが数字の比率と合う** | 目盛りがあれば目盛りで測る。ずれる（±10%超）なら目盛りを消させるのが一番確実 |
| D4 誇張がない | 小さい差を大きく見せる軸の切り方をしていない |

例 **M14**：0〜20年の目盛りで測ると「約17年」の棒が約19年、「約4年」が約5年 → 目盛りを消し、棒を約4分の1の長さに。

## E. 図の意味（★）

| 見ること | 合格 |
|---|---|
| E1 矢印の向き | 「何から何へ」を1本ずつ言葉にして確かめる（例：電力会社→家＝買う。家→電力会社だと「売る」に読める） |
| E2 余計な矢印・線 | 意味の違う矢印（ラベルから機器へ等）がない |
| E3 Before/After・左右の対比 | 左がBefore、右がAfter。明暗・色が指定どおり |
| E4 入力欄・選択肢の数が実際のフォームと同じ | フォームの図は、実際のフォームの項目数・種類と一致（**メールを聞かないのにメールのアイコン、はNG**） |

例 **M09**：一番下の矢印が家→電力会社（「売る」に読める）＋③のラベルから蓄電池への余計な矢印 → 2か所直す。
例 **M26**：ステップ2の入力欄が3つでメールのアイコン。実際のフォームは名前・電話の2つ → 2つに。

## F. 背景透過・余白（透過指定のコマは★）

| 見ること | 合格 |
|---|---|
| F1 本当に透過か | machine.json で上の角が透明。**見た目が透過風でも白で塗られていることがある**ので、必ずファイルで確かめる |
| F2 白い板・影が残っていない | 人物のまわりに白い縁や四角い板がない |
| F3 人物が切れていない | 上半身指定なら頭・肩が切れていない。少し引きで |
| F4 文字を載せる余白 | 「左半分は無地」等の指定があるコマ（最終CTAの背景）は、そこに何も描かれていない |

## G. 表現（★） — `expression_rules.md`

| 見ること | 合格 |
|---|---|
| G1 NG表現がない | 電気代0円・初期費用0円・〇%割引・先着・今だけ・No.1・必ず など、指定していない約束や数字がない |
| G2 体験談が効果の約束になっていない | 「◯円になった」でなく「数字で決められた」「急かされなかった」のような進め方の話 |
| G3 実在の会社・ロゴ・商標がない | 電力会社名・メーカー名・Amazonロゴなど |
| G4 注記が要る数字か | 要るなら「HTMLで入れる注記」に控える（画像には入れない） |

## H. 画風・つながり（減点のみ）

- 画風・線・塗りが他のコマとそろっている
- 場面のつながり（同じカフェ・同じリビング）
- 指定した擬音・効果線が入っている
- 画像の外枠（コマは黒の細線1本）

## 修正プロンプトの型

**直しは1通にまとめる**（何度も編集すると画質が落ち、別の所が崩れる）。設定シートを添付して送る。

```
{N}か所だけ直してください。それ以外（{変えないもの：見出し・文字・色・背景・構図・ポーズ など具体的に}）は変えないでください。
1. {どこを}：{今どうなっているか} → {どうしてほしいか。数・向き・色・大きさを具体的に}
2. …
```

項目別の言い方（実際に通ったもの）：

| NG | 送る文 |
|---|---|
| 人物のすり替え | 「右の女性を、添付のキャラクター設定シートの『なおこ』にしてください（茶色のショートボブ、小さな丸いピアス、からし色のニット、メガネなし、社員証なし）。ポーズはそのまま」— **「◯◯はやめて」も書く**（茶色の髪、ジャケット、メガネ等） |
| 人物が丸ごと違う（S02型） | 作り直し：「人物が違っています。添付のキャラクター設定シートの『みか』と『けんじ』で作り直してください」＋各人物の特徴を1行ずつ＋「なおこは描かない」＋サイズ・透過・文字なし |
| 文字の誤り | 「セリフの文字だけ直してください。『〇〇〇』と正確に。人物・背景・構図は変えない」 |
| 文字が小さい | 「2つの吹き出しの文字を、他のコマと同じ太いゴシック体にして、今の約2倍の大きさに。吹き出しも文字に合わせて大きく（顔にかからないように）。改行は『A／B／C』の3行」 |
| 棒と目盛りのずれ | 「グラフの下の目盛り線と数字を消してください。棒は『補助金なし』を長く、『補助金あり』を約4分の1の長さに」 |
| 矢印の向き | 「一番下の青い矢印の向きを逆にして、右下の電力会社の建物から家に向かう矢印にしてください（電力会社から家へ電気が来る向き）」 |
| 余計な矢印 | 「③のまわりのオレンジの矢印は、蓄電池から家の中へ向かう1本だけに。③のラベルから蓄電池に向かう矢印は消して」 |
| 入力欄の数 | 「ステップ2の入力欄を2つにしてください（人のアイコンと電話のアイコンだけ）。メールのアイコンと3つ目の入力欄は消して」 |
| 透過になっていない | 「背景を完全に透過したPNGで作り直してください。白い背景・影・床は入れない」 |
| 余計な小物 | 「テーブルのノートパソコンは消してください」（友人同士の場面が仕事の場面に見えるため） |

大きく外れたとき（人物が丸ごと違う・構図が指定と違う・判定AIが60点未満）は、編集でなく**同じプロンプトで新しく1枚**（前の画像は添付しない、設定シートだけ添付）。
