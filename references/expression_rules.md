# NG表現・景表法の注意と「要確認リスト」

漫画LPは「架空の人物の体験談」で進むので、**実例のように見せない**ことと、**根拠のない数字・約束を出さない**ことが一番の論点。参考LPには NG 表現がよく入っている（例：「初期費用0円」「電気代0円生活」「最大60%割引」「先着順」）。真似しない。

※法的な最終判断ではない。迷うものは要確認リストに入れ、クライアントまたは人が決める。

## 1. 使わない・言い換える表現

| 参考LPにありがちな表現 | このスキルでの扱い | 理由 |
|---|---|---|
| 電気代0円・0円生活・32,000円→0円 | 使わない。「電気代を気にせず」「約1割まで」など根拠のある範囲 | 基本料金が残る。優良誤認のおそれ |
| 初期費用0円・実質0円 | クライアントの実際の条件として書面で確認できた時だけ。条件（リース・ローン総額）を同じ画面に | 有利誤認のおそれ |
| 〇%割引・クーポン・キャンペーン価格 | 実在の条件がない限り使わない | 比較対象の価格がないと二重価格表示 |
| 先着〇名・まもなく終了・今だけ・本日限り | 実際の締切・枠がある時だけ。補助金は「予算がなくなり次第終了」まで | 根拠のない限定は有利誤認 |
| No.1・業界最安・日本一・満足度〇% | 調査機関・調査日・対象を注記できる時だけ | 根拠の注記がないと不当表示 |
| 必ず・絶対・確実に・〇円下がります | 「目安」「〜の場合」「変わります」 | 断定は優良誤認 |
| 架空の「お客様の声」「〇〇様の事例」 | 載せない。試算は「当社試算のモデルケース（実在のお客様の事例ではありません）」と明記 | 架空の体験談を実例に見せない |
| 漫画の体験談 | 漫画の前後に「※漫画はイメージです。登場人物は架空で、実在のお客様ではありません」 | 同上 |
| 体験談の中の効果（「◯円になった」） | 進め方の話にする（「数字を見て家族で決めた」「急かされなかった」） | 効果の約束になる |
| 実在の電力会社・メーカーの名前やロゴ | 画像に入れない。必要ならHTMLの出典つき注記で | 商標・誤認 |
| Amazonギフト等の特典 | 本文・漫画に出さず、CTAとフォームのまわりだけ。進呈条件と商標の注記をフォーム下に | 景品の上限・条件の明示。特典目当てのリードは成約しにくい（過去の案件の方針） |
| 「今日契約なら値引き」を悪く言う | 公的な数字（国民生活センター等）を出典つきで | 根拠のない他社批判にしない |

## 2. 数字の扱い

- 数字ごとに **出典（URL・資料名・日付）か「当社試算」か** を控える。どちらもない数字は使わない → `{{要確認}}`
- 計算で出す数字（30年で720万円、回収年数）は、式を注記に書く（「20,000円×12か月×30年の単純計算。値上がりは含みません」）
- 「最大」の数字（補助金の上限）は「対応エリアで最も高い制度の上限。地域で変わり、全額受け取れるとは限りません」
- 結果の幅（シミュレーター）は1つの数字に決めず、「目安」「〜円〜」と書き、条件で変わることを注記
- 図解の棒・比率は数字と合わせる（`panel_checklist.md` D）

## 3. 「要確認リスト.md」の出し方

工程②で作り始め、④⑤で足し、⑧の納品物に入れる。**人が答えるまで、該当箇所は `{{要確認：〜}}` のまま**か、未確定のまま載せない（過去の案件では保証・メーカー・設置実績・お客様の声・FAQ3問を、未確認のため削除した）。

```markdown
# 要確認リスト（{クライアント} 漫画LP）

| # | どこ | 内容 | いまの扱い | 誰に確認 | 状態 |
|---|---|---|---|---|---|
| 1 | M13・注記 | 補助金255万円・60万円の制度名と出典 | 「最大」の注記つきで掲載 | クライアント | 未 |
| 2 | 実例カード | 導入前後の金額（当社試算でよいか） | 「当社試算のモデルケース」と注記 | クライアント | 未 |
| 3 | フォーム | 送信先の番号（FORM_ID） | 仮で26 | 運用担当 | 未 |
| 4 | M14 | 回収年数の画像が古い数字（17年→4年） | そのまま | 人 | 未 |
```
分類：①数字の根拠 ②クライアントの事実（保証・実績・エリア・会社情報）③表現の判断 ④公開の設定（ドメイン・フォルダ・送信先・GTM）。

## 4. 機械チェック

`build_lp.py check` が `references/ng_words.txt` と、設定の `extra_ng_files` の語を本文から探して「確認」に出す。出たら、根拠と注記があるか、1つずつ判断する（「この値段は今日だけ」と言われたら…のように、注意喚起の文脈なら問題ない）。
